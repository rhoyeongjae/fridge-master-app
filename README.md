# Fridge Master (냉장고를 부탁해)

**Fridge Master**는 냉장고 속 식재료의 유통기한을 관리하고, 효율적인 식재료 소비를 돕는 React Native (Expo) 기반의 모바일 애플리케이션입니다.

---

## 주요 기능 (Key Features)

- 🛒 **식재료 등록 및 관리**: 냉장 / 냉동 / 실온 카테고리별 식재료 추가 및 수정
- ⏳ **유통기한 알림**: D-Day 계산을 통해 임박한 식재료 사전 알림 제공
- 📊 **소비 현황 분석**: 폐기되는 식재료 최소화를 위한 통계 및 리포트 (선택 사항)
